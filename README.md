# SNEAKERLAB — одностраничный лендинг

Готовый статический сайт без сборки и внешних зависимостей.

## Что сделано

- Десктопная версия визуально повторяет утверждённый макет.
- Адаптивная мобильная версия с тем же уличным стилем.
- Все кликабельные кнопки (навигация, бренды, поиск, избранное, корзина, «Выбрать модель») открывают модальное окно **«Техническое обслуживание»** с кнопкой **ОК**.
- Окно также закрывается по Escape или при клике на фон.
- Семантические элементы, aria-label и управление с клавиатуры.
- Netlify готов к публикации без сборки (`netlify.toml`).

## Локальный запуск

Откройте `index.html` в браузере. Или запустите локальный сервер:

```bash
python3 -m http.server 8080
```

Откройте http://localhost:8080

## Публикация на Netlify за минуту

1. Откройте https://app.netlify.com/drop
2. Перетащите **содержимое или архив проекта** в область загрузки.
3. Netlify создаст публичный адрес вида `https://...netlify.app`.
4. Для сохранения контроля над сайтом войдите в свою учётную запись Netlify и заявите права на проект.

## Загрузка на GitHub

Создайте на https://github.com/new новый пустой репозиторий, например `sneakerlab-landing`. Затем в распакованной папке проекта:

```bash
git init
git add .
git commit -m "Initial SNEAKERLAB landing"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/sneakerlab-landing.git
git push -u origin main
```

Замените `YOUR_USERNAME` своим логином и выполните авторизацию GitHub при запросе.

Чтобы Netlify обновлял сайт автоматически после каждого `git push`, в Netlify выберите «Add new project» → «Import an existing project» → GitHub → этот репозиторий. Параметры сборки не нужны, Publish directory: `.`.

## Заметки

Это **демонстрационный макет**, не настоящий интернет-магазин. Фирменные наименования принадлежат их правообладателям; изображения взяты из согласованного ИИ-макета и не являются официальными фотографиями или подтверждением партнёрства с брендами. Реальный каталог и заказы в этом проекте намеренно не реализованы.

Для точного соответствия десктопному дизайну он воспроизводится из оптимизированного макета со слоями интерактивных HTML-кнопок; мобильный вариант выполнен в HTML/CSS. Для дальнейшего развития магазина изображения и текст лучше разнести на независимые HTML-компоненты.
