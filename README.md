# SNEAKERLAB — версия 2

Одностраничный адаптивный сайт в уличном стиле, собранный на обычных HTML, CSS и JavaScript.

## Как устроен проект

- `index.html` — реальные текст, кнопки, навигация, преимущества и модальное окно.
- `styles.css` — уличный дизайн и адаптивные макеты для экранов от 320 px до ультрашироких мониторов.
- `script.js` — все кнопки открывают модальное окно «Техническое обслуживание», кнопка «ОК» его закрывает.
- `assets/air-jordan-cutout.webp` — отдельное изображение кроссовка с прозрачным фоном (из утверждённого макета).
- `assets/urban-wall.webp` — отдельная текстура фона без кнопок и надписей.
- `netlify.toml` — настройки публикации статического сайта на Netlify.

Здесь **нет** растянутой фотографии всего сайта и невидимых кликабельных областей. Все элементы — настоящие, с текстом и доступными подписями для экранных дикторов. Никакие пакеты и сборщики не требуются.

## Запуск локально

Откройте `index.html` в браузере. Для простого HTTP-сервера можно выполнить `python3 -m http.server 8000` из папки проекта и открыть http://localhost:8000.

## Как обновить GitHub и Netlify

1. Замените файлы репозитория на файлы из архива этой версии (включая папку `assets`). Удалите старые `assets/landing-desktop.webp` и `assets/sneaker-mobile.webp`, они больше не нужны.
2. Сделайте коммит в основную ветку (`main`).
3. Если Netlify уже связан с этим репозиторием, он сам создаст новую публикацию. Дублировать проект в Netlify не нужно.

Настройки Netlify: Build command — **пусто**, Publish directory — **`.`**.

### Без командной строки

Можно открыть репозиторий в GitHub Desktop (File → Clone repository), скопировать новые файлы в локальную папку репозитория и нажать Commit to main → Push origin. Это надёжнее для замены сразу нескольких существующих файлов, чем браузерная загрузка.

### Через терминал

```bash
cp -R /путь/к/sneakerlab-v2/. /путь/к/вашему/sneakerlab-landing/
cd /путь/к/вашему/sneakerlab-landing
git add -A
git commit -m "Rebuild landing with real responsive components"
git push origin main
```

*Независимая демонстрационная страница. Наименование брендов используется в целях визуального примера; проект не заявляет официального партнёрства с брендами.*
